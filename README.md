# psynthea-validation

> A scientific validation framework for evaluating, comparing and benchmarking synthetic clinical data generated by **psynthea** and **Synthea**.

---

## Overview

**psynthea-validation** is a research-oriented validation framework designed to evaluate the quality, consistency and realism of synthetic patient cohorts.

The framework was developed to support the validation of **psynthea**, a Python-native implementation of the Synthea Generic Module Framework, and to provide a reproducible methodology for comparing synthetic cohorts generated by different simulation engines.

Unlike a traditional analysis script, this project provides a modular framework capable of performing:

* descriptive cohort analysis;
* statistical validation;
* Java vs psynthea comparisons;
* clinical consistency checks;
* demographic validation;
* Spanish healthcare adaptation assessment;
* automatic report generation.

The project is intended for research, benchmarking and quality assurance rather than patient generation.

---

# Motivation

Synthetic clinical data are becoming increasingly important for:

* machine learning;
* epidemiological research;
* software testing;
* clinical decision support;
* privacy-preserving data sharing.

Generating synthetic patients is only one part of the problem.

A scientific workflow also requires answering questions such as:

* How realistic are the generated patients?
* Does the simulated population reproduce known epidemiological patterns?
* Are clinical pathways internally consistent?
* Does the Python implementation behave similarly to the original Synthea engine?
* Does the adaptation correctly represent the Spanish healthcare system?

This framework was created to answer those questions objectively.

# Objectives

The framework has four main objectives.

## 1. Internal validation

Verify that psynthea generates clinically coherent patients.

Examples:

* demographic consistency;
* encounter consistency;
* disease progression;
* medication coherence;
* observation integrity.

---

## 2. Statistical validation

Measure whether the generated cohorts reproduce expected statistical properties.

Examples:

* age distributions;
* sex distribution;
* disease prevalence;
* recurrence frequency;
* encounter rates.

---

## 3. Comparative validation

Compare cohorts generated by different simulation engines.

Initially:

* Synthea Java
* psynthea

Future extensions may include additional synthetic data generators.

---

## 4. Clinical validation

Assess whether generated cohorts follow expected clinical behaviour.

Examples:

* breast cancer should occur almost exclusively in women;
* prostate cancer should occur only in men;
* otitis media should primarily affect children;
* hypertension prevalence should increase with age.

# Installation

Clone the repository.

```bash
git clone <repository-url>

cd psynthea-validation
```

Create the Conda environment.

```bash
conda env create -f environment.yml
```

Activate the environment.

```bash
conda activate psynthea-validation
```

Verify the installation.

```bash
python --version

pytest --version
```

# Running the framework

A complete validation will eventually be executed through a single command.

Example.

```bash
python -m validation.cli \
    --input data/raw/psynthea \
    --output reports/
```

The framework will automatically:

1. load the cohort;
2. compute descriptive statistics;
3. perform statistical validation;
4. generate figures;
5. create a validation report.

# Statistical Analysis

* descriptive statistics;
* confidence intervals;
* Chi-square tests;
* Kolmogorov–Smirnov tests;
* Student's t-tests;
* Mann–Whitney U tests;

Additional methods may be incorporated as required.
